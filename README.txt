Expense Tracker
Автор: Казанцев Роман Денисович
Простое приложение для учёта личных расходов с графическим интерфейсом. 
Позволяет добавлять траты, фильтровать их по категориям и датам, а также видеть итоговую сумму за выбранный период. 
Все данные сохраняются в файл data/expenses.json.

Как запустить
Убедитесь, что у вас установлен Python 3.
Запустите программу

Как пользоваться
Добавление расхода
Введите сумму (например, 150.5).
Выберите категорию из списка (например, «Еда»).
Укажите дату в формате ГГГГ-ММ-ДД (например, 2026-04-30).
Нажмите кнопку «Добавить расход».
Фильтрация и подсчёт суммы
В блоке «Фильтр по категории» выберите нужную категорию или оставьте «Все».
Введите даты начала и окончания периода в формате ГГГГ-ММ-ДД.
Нажмите кнопку «Обновить».
Появится окно с итоговой суммой расходов за выбранный период.
Примеры использования
Добавить расход на транспорт:
Сумма: 100
Категория: Транспорт
Дата: 2026-04-29
Действие: Нажать «Добавить расход».
Посчитать расходы на еду за неделю:
Фильтр по категории: Еда
Дата с: 2026-04-24
Дата по: 2026-04-30
Действие: Нажать «Обновить».
Проверка валидации:
Попробуйте ввести отрицательную сумму (например, -50) — появится сообщение об ошибке.
Попробуйте ввести дату в неверном формате (например, 30/04/26) — появится сообщение об ошибке.
