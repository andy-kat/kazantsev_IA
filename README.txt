Программа "Перевод валют"
Автор: Казанцев Роман Денисович
Описание:
Простая программа на Python для конвертации российских рублей (RUB) в другие валюты с помощью API ExchangeRate. Интерфейс реализован на tkinter.

Как использовать:
Введите сумму в рублях.
Выберите нужную валюту из списка.
Нажмите «Перевести».
Результат появится под кнопкой.
Пример использования:
Сумма в RUB: 1000
Выберите валюту: USD
[Перевести]
Результат: 11.20 USD
Примечание:
Курсы валют загружаются автоматически при запуске программы. Для работы требуется подключение к интернету.
Использован сервис для перевода валют вместо API ключа из за невозможности подключения
