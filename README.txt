Конвертер валют
Простое приложение с графическим интерфейсом для конвертации валют.Работает без API-ключа.

Возможности
Двунаправленная конвертация: выбор валюты «из» и «в».
История операций: все переводы сохраняются в таблицу и файл.
Сохранение данных: история сохраняется в conversion_history.json.
Валидация: проверка на пустое поле и положительную сумму.
Кросс-курсы: конвертация между любыми валютами через RUB.
Запуск
Установите Python 3.8+.
Установите зависимости:
bash
Копировать
pip install requests tkcalendar
Запустите скрипт:
bash
Копировать
python currency_converter.py
Для работы программы требуется подключение к интернету (загрузка курсов).
Использование
Введите сумму для перевода.
Выберите валюту «Из» и «В».
Нажмите кнопку «Перевести».
Результат появится под кнопкой и будет добавлен в таблицу истории.
Копировать
| Из | В | Сумма | Курс | Результат |
|----|---|-------|------|-----------|
| RUB | USD | 100.00 | 0.0112 | 1.12 USD |
